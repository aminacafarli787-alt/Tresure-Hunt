# Treasure Hunt Game (C)

A console-based Treasure Hunt game developed using the C programming language.

## About the Project
The game takes place on an 8×8 grid where players search for hidden treasures while avoiding traps. Players have limited lives and can use a scanner to help find treasures.

## Features
- Random placement of treasures and traps
- 8×8 game board
- Limited player lives
- Scanner functionality
- Win and lose conditions

## Technologies Used
- C Programming Language
- Standard C Libraries
- Random Number Generation

## How to Run

Compile the program:

```bash
gcc treasure_hunt.c -o treasure_hunt
```

Run the game:

```bash
./treasure_hunt
```
